# Pilot Go-Live Checklist

## Deployment

- [ ] Correct environment confirmed.
- [ ] Correct database confirmed.
- [ ] Build passes.
- [ ] App starts.
- [ ] Login page loads.

## Backups

- [ ] Database backup created.
- [ ] Backup file verified.
- [ ] `.env` backed up securely.
- [ ] Restore drill completed or scheduled.

## Monitoring

- [ ] Platform Health & Analytics checked.
- [ ] Database Health checked.
- [ ] Audit Center checked.
- [ ] Alert monitoring reviewed.
- [ ] Support owner assigned.

## Scanner

- [ ] Staff scanner tested.
- [ ] Branch scanner tested.
- [ ] Android tested.
- [ ] iPhone tested.
- [ ] Manual token fallback tested.

## Rewards

- [ ] Reward Ready state tested.
- [ ] Reward redemption tested.
- [ ] Staff restriction tested.

## Referrals

- [ ] Referral link opens.
- [ ] Pending referral tested.
- [ ] First stamp qualification tested.
- [ ] Self-referral blocked.

## Billing Center

- [ ] Subscription visible.
- [ ] Invoice page loads.
- [ ] Payment tracking understood.

## Audit Center

- [ ] Audit Center loads.
- [ ] Filters work.
- [ ] Event detail opens.

## Tenant Center

- [ ] Tenant appears.
- [ ] Tenant health visible.
- [ ] Branding state visible.

## Business Accounts

- [ ] System Administrator login works.

## Customer Journey

- [ ] Customer enrolled.
- [ ] Customer card opens.
- [ ] QR appears.

## Sign-Off
