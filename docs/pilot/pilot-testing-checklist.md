# Pilot Testing Checklist

Use this checklist for each pilot business before go-live.

## Platform Setup

- [ ] Business created
- [ ] Subscription plan assigned
- [ ] Subscription status verified as Trial or Active
- [ ] Business Owner account created
- [ ] Business Owner login tested
- [ ] Demo Mode enabled if this is a demo environment
- [ ] Launch Readiness page checked
- [ ] Platform Health checked

## Business Setup

- [ ] Branches created
- [ ] Branch Manager user created
- [ ] Staff user created
- [ ] Business Owner dashboard opened
- [ ] Onboarding checklist reviewed

## Loyalty Setup

- [ ] Loyalty program created
- [ ] Required stamps configured
- [ ] Starting bonus stamps configured
- [ ] Reward configured
- [ ] Customer enrolled
- [ ] Customer enrolled into loyalty program

## Customer Card

- [ ] Customer card opened
- [ ] Public card URL works
- [ ] QR code visible
- [ ] Card link copied
- [ ] WhatsApp share link checked manually

## Scanner and Stamps

- [ ] QR scanned by Staff
- [ ] QR scanned by Branch Manager
- [ ] Stamp issued
- [ ] Multi-stamp reason tested
- [ ] Earned stamps increased
- [ ] Bonus stamps unchanged
- [ ] Scan event recorded

## Alerts and Fraud Monitoring

- [ ] Multiple-stamp alert generated
- [ ] Alert appears in Notifications
- [ ] Investigate Alert link works
- [ ] View Customer link works
- [ ] View Activity link works
- [ ] Alert reviewed
- [ ] Alert dismissed if needed

## Reward Redemption

- [ ] Reward Ready state tested
- [ ] Staff cannot redeem reward
- [ ] Branch Manager can redeem reward
- [ ] Business Owner can redeem reward
- [ ] Reward redemption history appears
- [ ] Earned stamps reset after redemption
- [ ] Bonus stamps restored after redemption

## Engagement and Messages

- [ ] Welcome event created
- [ ] Near Reward event created if applicable
- [ ] Reward Ready event created
- [ ] Reward Redeemed event created
- [ ] Message prepared
- [ ] Message appears in outbox
- [ ] Message copied
- [ ] Message marked Sent Manually
- [ ] Cancel message tested

## Exports

- [ ] Customer CSV export tested
- [ ] Program CSV export tested
- [ ] Redemption CSV export tested
- [ ] Alert CSV export tested

## Final Pilot Sign-Off

- [ ] Business Owner understands manual message sending
- [ ] Branch Manager understands scanner and redemption flow
- [ ] Staff understands stamp issuance flow
- [ ] Known limitations shared with pilot business
- [ ] Support contact shared with pilot business
