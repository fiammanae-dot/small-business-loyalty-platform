# Pilot Documentation Index

This folder contains pilot onboarding, training, support, operations, and launch-readiness documentation for LoyaltyBase.

## Pilot Operations

- `pilot-onboarding-guide.md`: pilot purpose, timeline, expectations, responsibilities, communication, issue reporting, and completion process.
- `support-operations-manual.md`: support levels, issue categories, escalation, response expectations, documentation, and closure process.
- `incident-classification-matrix.md`: P1-P4 severity definitions, examples, response targets, escalation path, and resolution targets.
- `pilot-success-scorecard.md`: pilot usage, reliability, support, and satisfaction scorecard.
- `pilot-completion-report-template.md`: final report template for pilot review.
- `launch-readiness-review.md`: readiness assessment for platform, operations, support, pilot, and commercial readiness.

## Role Guides

- `platform-owner-pilot-guide.md`: System Administrator pilot setup and monitoring guide.
- `business-owner-user-guide.md`: full Business Owner user guide.
- `business-owner-quick-start.md`: short Business Owner onboarding guide.
- `branch-manager-user-guide.md`: Branch Manager user guide.
- `branch-manager-operations-guide.md`: daily Branch Manager operations guide.
- `staff-user-guide.md`: Staff user guide.
- `staff-operations-guide.md`: daily Staff operations guide.

## Testing And Launch

- `pilot-testing-checklist.md`: pilot business testing checklist.
- `go-live-checklist.md`: final pilot go-live checklist.
- `pilot-database-setup.md`: clean pilot database setup guide.
- `backup-restore-guide.md`: pilot backup and restore guide.
- `known-limitations.md`: known pilot limitations.
- `pilot-faq.md`: FAQ for Business Owners, Branch Managers, Staff, Customers, scanner usage, referrals, rewards, billing, and support.

## Recommended Pilot Flow

1. Read `pilot-onboarding-guide.md`.
2. Prepare environment with `pilot-database-setup.md`.
3. Confirm known limitations with `known-limitations.md`.
4. Train System Administrator with `platform-owner-pilot-guide.md`.
5. Train Business Owner with `business-owner-quick-start.md`.
6. Train Branch Manager with `branch-manager-operations-guide.md`.
7. Train Staff with `staff-operations-guide.md`.
8. Run `pilot-testing-checklist.md`.
9. Complete `go-live-checklist.md`.
10. Track pilot results in `pilot-success-scorecard.md`.
11. Complete `pilot-completion-report-template.md`.

## Operating Rules

- Do not use development test data for real pilot customers.
- Do not modify `loyalty_platform_pilot` unless pilot work is explicitly approved.
- Keep support manual and incident matrix available during pilot.
- Record known issues and outcomes before making go/no-go decisions.
