# Support Operations Manual

This manual defines pilot support operations.

## Support Levels

Level 1:

Basic user support, password guidance, navigation questions, scanner usage.

Level 2:

Workflow troubleshooting, customer enrollment issues, staff access issues, alert review help.

Level 3:

Technical investigation, data isolation questions, database health, deployment issues.

## Issue Categories

- Login and access.
- Customer enrollment.
- Scanner and QR.
- Stamp issuance.
- Reward redemption.
- Referral flow.
- Billing and subscription.
- Alerts and notifications.
- Mobile layout.
- Platform operations.

## Escalation Path

1. Staff reports to Branch Manager.
2. Branch Manager reports to Business Owner.
3. Business Owner reports to Platform support.
4. Platform support escalates to technical owner if needed.

Critical issues can skip intermediate steps.

## Response Expectations

P1 Critical:

Immediate response.

P2 High:

Response within 30 minutes during pilot hours.

P3 Medium:

Response same business day.

P4 Low:

Response within two business days.

## Documentation Process

For each issue record:

- Business.
- User.
- Role.
- Device.
- Browser.
- Page.
- Steps.
- Expected result.
- Actual result.
- Severity.
- Status.
- Owner.

## Issue Closure Process

Close issue only when:

- Root cause is understood or workaround accepted.
- Affected user confirms resolution.
- Notes are documented.
- Follow-up task is created if needed.
