# Business Owner Quick Start

This guide helps Business Owners start using Loyalty Card UAE during pilot.

## Login

1. Open the login page.
2. Enter your email and temporary password.
3. Sign in.
4. Confirm you land on the Business dashboard.

## Dashboard Overview

The dashboard shows:

- Business overview.
- Today activity.
- Customers.
- Risk alerts.
- Messages.
- Quick actions.
- Onboarding checklist.

Start with the primary actions:

- Add Customer.
- Open Scanner.
- Loyalty Programs.
- Notifications.

## Create Branch

1. Open Business -> Branches.
2. Select Add Branch.
3. Enter branch name, country, city, and address.
4. Save.

Note:

Your subscription plan controls the number of branches allowed.

## Create Staff

1. Open Business -> Staff.
2. Add Branch Manager or Staff.
3. Assign user to branch.
4. Share temporary password securely.

Do not create shared staff accounts. Each staff member should have their own login.

## Create Loyalty Program

1. Open Business -> Programs.
2. Select Create Program.
3. Choose template if useful.
4. Enter required stamps.
5. Enter reward.
6. Save.

Common rule:

Starting bonus stamps cannot exceed required stamps.

## Enroll Customer

1. Open Business -> Customers.
2. Select Add Customer.
3. Enter first name and phone.
4. Add optional email, birthday, branch, consent, and notes.
5. Save.

The system creates a customer card and membership.

## Review Analytics

Use:

- Dashboard KPIs.
- Program details.
- Customer profile.
- Notifications.
- Engagement Center.

Advanced platform-wide analytics are managed by System Administrator.

## Review Referrals

Customers can share referral links from their public card.

Business Owner can review:

- Pending referrals.
- Qualified referrals.
- Referral rewards granted.
- Top referrers.

## Review Alerts

Open Business -> Notifications.

Use filters:

- Severity.
- Priority.
- Status.
- Branch.
- Assigned user.
- Rule type.

Actions:

- Assign.
- Review.
- Escalate.
- Resolve.
- Dismiss.

## Common Mistakes

- Creating duplicate staff accounts.
- Forgetting to assign staff to a branch.
- Creating a program without enrolling customers.
- Thinking prepared messages are sent automatically.
- Forgetting that multiple stamps require a reason.
- Trying to exceed branch or program limits.
