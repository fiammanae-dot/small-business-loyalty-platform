# Branch Manager User Guide

This guide explains how Branch Managers use LoyaltyBase during the pilot.

## Branch Dashboard

After signing in, Branch Managers open the Branch dashboard.

The dashboard shows:

- Branch name
- Business name
- Branch performance
- Customer count
- Stamps issued at the branch
- Rewards redeemed at the branch
- Open alerts for the branch

## View Branch Customers

Open:

Branch -> Business customers

Customers belong to the whole business, not only one branch. Branch Managers can search and open customers from the same business.

Branch performance reporting should be interpreted by branch transaction activity, not by customer ownership.

## Open Scanner

Open:

Branch -> Scanner

Paste a scan token or full scan URL. The scan result page validates whether the QR belongs to the same business.

## Issue Stamps

On a valid scan result, use Add Stamp.

Rules:

- Quantity can be 1 to 5.
- Reason is required when issuing more than 1 stamp.
- Earned stamps increase.
- Bonus stamps do not change.

## Redeem Rewards

Branch Managers can redeem rewards when the scan result shows Reward Ready.

After redemption:

- Reward redemption is recorded.
- Earned stamps reset.
- Bonus stamps return to the program starting bonus.

## Restricted Actions

Branch Managers cannot:

- Create businesses
- Edit subscription plans
- Create or edit loyalty programs
- Manage invoices
- Access System Administrator pages
- Access Business Owner setup pages

These restrictions protect business configuration and billing controls.

## Invalid or Wrong-Business QR

If the scanner shows invalid, disabled, or wrong-business QR:

1. Ask the customer to open their latest loyalty card.
2. Confirm the card belongs to the current business.
3. Ask the Business Owner if the card or program was disabled.
4. Do not issue stamps outside the scanner flow.
