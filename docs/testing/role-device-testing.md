# Role-Based Device Testing

Use this checklist to validate each role on mobile and desktop devices.

## System Administrator

Verify:

- [ ] Login.
- [ ] Navigation.
- [ ] Dashboard.
- [ ] Businesses.
- [ ] Plans.
- [ ] Subscriptions.
- [ ] Invoices.
- [ ] Audit Center.
- [ ] Billing Center.
- [ ] Tenant Center.
- [ ] Settings.
- [ ] Logout.
- [ ] Mobile experience for emergency operations.

## Business Owner

Verify:

- [ ] Login.
- [ ] Dashboard.
- [ ] Customers.
- [ ] Customer profile.
- [ ] Programs.
- [ ] Notifications.
- [ ] Engagement.
- [ ] Messages.
- [ ] Billing.
- [ ] Settings.
- [ ] Logout.
- [ ] Mobile experience for daily operations.

## Branch Manager

Verify:

- [ ] Login.
- [ ] Branch dashboard.
- [ ] Customers.
- [ ] Programs.
- [ ] Scanner.
- [ ] Stamp issuance.
- [ ] Reward redemption.
- [ ] Logout.
- [ ] Mobile scanner experience.

## Staff

Verify:

- [ ] Login.
- [ ] Staff dashboard.
- [ ] Customer enrollment.
- [ ] Enrollment success page.
- [ ] Scanner.
- [ ] Stamp issuance.
- [ ] Restricted access blocked.
- [ ] Logout.
- [ ] Mobile scanner experience.

## Customer

Verify:

- [ ] Public card opens.
- [ ] Referral page opens.
- [ ] WhatsApp share works manually.
- [ ] QR displays.
- [ ] Mobile layout works.
- [ ] Tablet layout works.

## Logout Verification

For authenticated roles:

- [ ] Logout clears session.
- [ ] Refresh after logout does not restore session.
- [ ] Login page requires credentials again.
