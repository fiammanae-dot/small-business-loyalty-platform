# Pilot E2E Master Checklist

Use this checklist before pilot onboarding.

## System Administrator

- [ ] Login works.
- [ ] Dashboard loads.
- [ ] Business can be created.
- [ ] Plan can be assigned.
- [ ] Business Owner can be created.
- [ ] Subscription can be activated.
- [ ] Tenant appears in Tenant Center.
- [ ] Billing Center loads.
- [ ] Audit Center loads.
- [ ] Analytics loads.

## Business Owner

- [ ] Login works.
- [ ] Dashboard loads.
- [ ] Branch can be created within plan limit.
- [ ] Staff user can be created.
- [ ] Loyalty program can be created.
- [ ] Customer can be created.
- [ ] Customer can be enrolled into program.
- [ ] Customer profile loads.
- [ ] Notification workflow works.
- [ ] Message preparation works.
- [ ] Billing view is read-only.

## Branch Manager

- [ ] Login works.
- [ ] Branch dashboard loads.
- [ ] Customer list loads.
- [ ] Customer can be enrolled.
- [ ] Programs are visible.
- [ ] Scanner opens.
- [ ] Valid QR scan works.
- [ ] Stamp issuance works.
- [ ] Reward redemption works when customer is reward-ready.
- [ ] Wrong-business QR is blocked.

## Staff

- [ ] Login works.
- [ ] Staff dashboard loads.
- [ ] Customer enrollment works.
- [ ] Success page shows card URL.
- [ ] Scanner opens.
- [ ] Valid QR scan works.
- [ ] One stamp issuance works.
- [ ] Multiple stamp reason validation works.
- [ ] Staff cannot redeem reward.
- [ ] Staff cannot access management pages.

## Customer

- [ ] Public card opens.
- [ ] Phone is masked.
- [ ] Branding is visible.
- [ ] Loyalty progress displays.
- [ ] QR code displays.
- [ ] Referral link displays.
- [ ] Invalid card shows safe message.

## Sign-Off

- [ ] No critical findings remain.
- [ ] No high findings remain without workaround.
- [ ] Mobile scanner has been tested.
- [ ] Tenant isolation has been tested.
- [ ] Pilot owner approves launch.
