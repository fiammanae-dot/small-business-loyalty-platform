# Mobile Performance Checklist

Use this checklist to evaluate performance before pilot onboarding.

## Acceptable Targets

Initial pilot targets:

- Dashboard load: under 3 seconds on stable Wi-Fi.
- Scanner page load: under 3 seconds on stable Wi-Fi.
- Customer card load: under 2 seconds on stable Wi-Fi.
- Referral page load: under 2 seconds on stable Wi-Fi.
- Customer list search response: under 2 seconds for pilot-sized data.
- Program list load: under 2 seconds for pilot-sized data.

## Dashboard Load Speed

- [ ] Platform dashboard loads within target.
- [ ] Business dashboard loads within target.
- [ ] Branch dashboard loads within target.
- [ ] Staff dashboard loads within target.

## Scanner Load Speed

- [ ] Staff scanner loads within target.
- [ ] Branch scanner loads within target.
- [ ] Camera starts quickly after permission.
- [ ] Manual token input is immediately usable.

## Customer Card Load Speed

- [ ] Public card loads within target.
- [ ] QR appears quickly.
- [ ] Branding does not block rendering.

## Referral Page Load Speed

- [ ] Referral page loads within target.
- [ ] Share actions are visible.

## Large Lists

Test with the largest available QA data:

- [ ] Customer list remains usable.
- [ ] Program list remains usable.
- [ ] Notification list remains usable.
- [ ] Message list remains usable.
- [ ] Platform business list remains usable.
