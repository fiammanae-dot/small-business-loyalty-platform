# Mobile Responsiveness Checklist

Use this checklist to validate responsive behavior across role surfaces.

## General Checks

- [ ] No horizontal scrolling.
- [ ] Header and navigation fit.
- [ ] Buttons are touch-friendly.
- [ ] Text does not overlap.
- [ ] Filters are usable.
- [ ] Tables convert to cards where expected.
- [ ] Forms fit screen width.
- [ ] Modals or panels are usable.
- [ ] Charts are readable.
- [ ] Empty states are readable.
