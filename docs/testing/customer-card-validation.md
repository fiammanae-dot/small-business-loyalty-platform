# Customer Card Validation

Use this checklist to validate the public customer card.

## Card Loading

- [ ] Customer card loads without login.
- [ ] Invalid token shows Card not available.
- [ ] Disabled card shows Card not available.
- [ ] Page does not expose internal IDs.
- [ ] Page loads on mobile.
- [ ] Page loads on tablet.

## Branding

- [ ] Business logo appears when configured.
- [ ] Business name appears.
- [ ] Business type appears.
- [ ] Primary color is applied.
- [ ] Secondary color is applied.
- [ ] Text remains readable.
- [ ] Buttons remain readable.

## Membership

- [ ] Customer name appears.
- [ ] Phone number is masked.
- [ ] Member since date appears.
- [ ] Membership status appears.
- [ ] Card status appears.

## Loyalty Program Section

- [ ] Program name appears.
- [ ] Stamp count appears.
- [ ] Progress is accurate.
- [ ] Reward name appears.
- [ ] Reward status appears.
- [ ] QR code appears.
- [ ] QR is not oversized.

## Referral Section

- [ ] Referral section appears.
- [ ] Referral link exists.
- [ ] Copy referral link works.
- [ ] WhatsApp share opens manual share.
- [ ] Pending referrals count appears.
- [ ] Qualified referrals count appears.
- [ ] Rewards earned count appears.

## Layout

- [ ] Mobile layout has no horizontal scroll.
- [ ] Tablet layout is readable.
- [ ] Wallet placeholders are clearly non-integrated.
- [ ] Future sections do not look broken.

## Pass Criteria

Customer card is ready when a customer can:

- Open card.
- Understand progress.
- Show QR to staff.
- Share referral link.
- Use the page comfortably on phone.
